# 03 — International / cross-border open data, live feeds and crisis-map case studies

*Research date: 2026-10-09. Scope: data and lessons usable for the Ogres novads interactive civil-protection (CA) Web-GIS map.*
*Legend: ✅ = endpoint verified live during this research; ◐ = documented by a primary or secondary source but not tested; ⚠ = needs a check or registration.*

**Already in `avoti/` (not re-proposed here):** 112.lv public shelters (GeoJSON/CSV, 31 in Ogre), VZD VARIS addresses and NĪVKIS cadastre (incl. basements), LVĢMC flood-risk WMS (10/100/200-year) and hydrological levels, LVC NAP road network plus DATEX II closures/ice, black spots, bridge tonnage, the dangerous-goods rail corridor, CA plan Tables 26/27 (evacuation assembly points and accommodation centres) and the administrative boundaries.

#### Crisis-relevant OSM tags (Overpass, inside `area["name"="Ogres novads"]`)

| Theme | Tags |
|---|---|
| Shelter / refuge | `amenity=shelter` + `shelter_type=*` (mostly bus stops, so filter), `building=bunker`, `emergency=assembly_point`, `social_facility=shelter` |
| Emergency services | `amenity=fire_station`, `amenity=police`, `emergency=ambulance_station`, `emergency=fire_hydrant`, `emergency=defibrillator` (AED), `emergency=siren` (+`siren:type`) |
| Health | `amenity=hospital`, `amenity=clinic`, `amenity=doctors`, `amenity=pharmacy`, `healthcare=*`, `healthcare=dialysis`, `amenity=dentist` |
| Vulnerable people | `amenity=social_facility` + `social_facility=nursing_home/group_home/assisted_living`, `amenity=kindergarten`, `amenity=school`, `amenity=prison` |
| Water | `amenity=drinking_water`, `man_made=water_well` / `water_tap` / `water_tower` / `water_works` / `wastewater_plant`, `pump=*` |
| Power | `power=substation`, `power=plant`, `power=generator`, `power=line` (tree-fall exposure), `backup_generator=yes` (rare) |
| Telecom | `man_made=mast` / `communications_tower` + `communication:mobile_phone=yes`, `telecom=exchange` |
| Supplies | `amenity=fuel`, `shop=supermarket` / `convenience`, `amenity=atm`, `amenity=bank`, `shop=hardware`, `amenity=charging_station` |
| Heat / gathering | `amenity=community_centre`, `amenity=place_of_worship`, `leisure=sports_hall`, `amenity=townhall`, `amenity=library` (warming/charging candidates) |
| Transport | `bridge=yes` + `highway=*` (with `maxweight`), `railway=station`, `aeroway=helipad`, `amenity=bus_station`, `amenity=ferry_terminal` |
| Hazards | `man_made=dam`, `waterway=dam/weir`, `industrial=*`, `landuse=industrial`, `hazard=*`, `man_made=storage_tank` + `content=*`, `pipeline=gas` |

Example query (generate with an LLM per theme, then cache as GeoJSON):
```
[out:json][timeout:90];
area["name"="Ogres novads"]["boundary"="administrative"]->.a;
( nwr(area.a)["amenity"~"pharmacy|fuel|drinking_water|social_facility"];
  nwr(area.a)["power"~"substation|generator"];
  nwr(area.a)["emergency"]; );
out center tags;
```

### Cross-cutting lessons → design rules for the Ogre map
1. **Offline first:** use a PWA with cached tiles and GeoJSON plus a printable PDF per pagasts (Iberia: mobile data lost within about 2 hours; Ukraine: Diia offline).
2. **Static and CDN-hosted for the public mode** (Sweden: traffic rose 16× on day one).
3. **Show service status, not just location.** Store attributes such as `has_generator`, `heated`, `water`, `charging`, `internet`, `open_now`, `accessible`, `overnight` (Points of Invincibility, Texas).
4. **"Last verified" date and a citizen "report status" button** on every object (Kyiv).
5. **Pre-agreed thresholds wired to map zones** produce a draft alert automatically (Valencia).
6. **Two security tiers with a war-mode switch.** Critical infrastructure and capacities appear only in the commission mode; the public mode shows only the help points (Ukraine OPSEC).
7. **Multi-channel:** the map shows the radio frequency, sirens, 112 and printed locations, never the map alone (Gudrun, Iberia, Ciarán).
8. **Keep crowd data and official data in separate layers,** with TTL and verification (afetharita).
