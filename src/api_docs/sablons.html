Mēs ne tikai lietojam atvērtos datus — mēs tos arī publicējam. Viss, ko rāda karte, ir pieejams kā atvērts JSON API: {{SKAITS}} galapunkti, katram avots, licence un keša laiks. Bez atslēgas, bez reģistrācijas.

  • Licence. Mūsu atvasinātie dati (biežāk meklētais, iedzīvotāju ziņojumi, satiksmes zonas, pašvaldību apkopojums, statuss) — CC BY 4.0, atsauce „map.repo.lv”. Caurlaistie dati — avota licence (norādīta pie katra galapunkta; punktiem — properties.avots un /api/avoti). 112.lv patvertnēm atvērta licence nav norādīta.
  • CORS: visi GET galapunkti atļauti no jebkuras vietnes (Access-Control-Allow-Origin: *). POST galapunkti ir tikai šai lapai.
  • Saudzīgi, lūdzu: atbildes ir kešotas (Cache-Control); netaisiet vairāk par ~1 pieprasījumu sekundē no vienas lietotnes un kešojiet paši. Ārējie avoti (LVĢMC, FMI, NAP, OSRM) tiek sasniegti tikai caur mūsu kešu.
  • Formāts: JSON (UTF-8), koordinātas WGS-84; kļūdas — {"kluda": "…"} ar HTTP 400 / 404 / 503.
  • Mašīnlasāmi: openapi.json (OpenAPI 3.1) — der jebkuram OpenAPI rīkam.

Kā lietot savā lietotnē

const r = await fetch('https://map.repo.lv/api/objekti?kategorijas=patvertne&lat=56.95&lon=24.11&limit=3');
const { features } = await r.json();   // tuvākās 3 patvertnes, sakārtotas pēc attāluma (properties.attalums_m)

/api/veseliba?statistika=1 — ko nozīmē skaitītāji

  • ok — datubāze atbild.
  • statistika.kesa.<avots>: no_kesas — atbildēts no kešas; uz_avotu — cik reižu tiešām pieprasīts ārējais avots; novecojusi — atdota novecojusi vērtība, kamēr fonā atjauno (lietotājs negaida); gaidija — pieprasījums gaidīja, jo vērtības vēl nebija nemaz.
  • db_vaicajumi — datubāzes vaicājumi kopš palaišanas; db_parslodze — cik reižu visi db_vienlaicigi savienojumi bija aizņemti 10 s (atbilde 503); pavedieni — aktīvie pavedieni.
